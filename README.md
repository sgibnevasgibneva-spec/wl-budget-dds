# WL | Бюджет ДДС

Код действующего проекта Google Apps Script. История Git хранит исходный код, но не содержит данные Google Sheets, ключи доступа или настройки пользователей.

Перед обновлением: скачать текущий код проекта, сверить с Git и сохранить резервную копию. Для восстановления данных нужна отдельная резервная копия Google-таблицы.

Важно: не использовать `clasp deploy` для обновления действующего веб-приложения без проверки типа и настроек доступа: эта команда ранее заменила тип развёртывания. Сохранять действующий адрес и права.
